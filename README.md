# Video Vault — אתר צפייה בסרטון עם קוד אישי

אתר קטן שמגיש סרטון רק למי שמזין קוד צפייה תקף.

- **קוד אחר לכל צופה**, עם **תאריך תפוגה**. אחרי התאריך הקוד מפסיק לעבוד, גם באמצע צפייה.
- **נעילה למכשיר**: קוד שהופעל בדפדפן אחד לא יעבוד בדפדפן אחר (אפשר לאפשר 2, 3 או יותר מכשירים). כך אי אפשר פשוט להעביר את הקוד לחבר.
- **ביטול מיידי**: מבטלים קוד והצפייה נחסמת תוך דקות.
- **אין קישור מקורי להעביר**: הסרטון מחולק להרבה קטעים קטנים ומוצפנים (HLS + AES-128). מפתח הפענוח נשלח רק לדפדפן מחובר.
- **סימן מים זז** עם שם הצופה והקוד שלו מעל הווידאו, גם במסך מלא. אם מישהו מקליט מסך ומפיץ, רואים מי הדליף.
- **פאנל ניהול** (`/admin`): יצירת קודים, שינוי תוקף, איפוס מכשירים, ביטול, העלאת סרטונים.
- **חינם**: רץ על Cloudflare Workers + R2 + KV, בתוך המכסה החינמית.

## מה אפשר להגן ומה לא (חשוב לקרוא)

| איום | האם נחסם? |
|---|---|
| מישהו בלי קוד נכנס לאתר | ✅ נחסם |
| צופה מעביר את הקישור לאחר | ✅ הקישור לבד לא שווה כלום, צריך קוד |
| צופה מעביר את הקוד לאחר | ✅ נחסם בזכות הנעילה למכשיר (אם בחרת "מכשיר אחד") |
| צפייה אחרי תאריך התפוגה | ✅ נחסם |
| "לחיצה ימנית > שמירת וידאו", כפתור הורדה | ✅ אין כזה |
| תוספי הורדה פשוטים לדפדפן | 🟡 רובם לא מתמודדים עם HLS מוצפן, אבל חלק כן |
| משתמש טכני עם כלים כמו yt-dlp + ה-cookies שלו | ❌ יכול להוריד, כי הדפדפן שלו מקבל את המפתח באופן לגיטימי |
| הקלטת מסך | ❌ אי אפשר לחסום מאתר אינטרנט. **סימן המים** מרתיע ומזהה את המדליף |
| צילום המסך עם טלפון | ❌ אף טכנולוגיה לא חוסמת את זה |

**על הקלטת מסך:** הדבר היחיד שמשחיר את המסך בהקלטה הוא DRM "אמיתי" (Widevine/FairPlay, מה שנטפליקס משתמשת בו).
זה דורש שירות בתשלום (למשל VdoCipher, או Bunny Stream עם DRM), ובדרך כלל
לא עוזר בכל הדפדפנים. גם עם DRM אפשר לצלם את המסך בטלפון. לכן הפתרון המקובל, גם אצל גופים גדולים, הוא **סימן מים אישי**,
וזה מה שהאתר הזה עושה.

**למה לא יוטיוב לא-רשום?** נגן יוטיוב תמיד חושף את מזהה הסרטון בקוד הדף, וכל מי שיפתח את "כלי המפתחים" יראה את הקישור ויוכל להעביר אותו.

## התקנה (פעם אחת, בערך 20 דקות)

### 1. מה צריך
- חשבון חינמי ב-[Cloudflare](https://dash.cloudflare.com/sign-up).
- [Node.js](https://nodejs.org) (גרסת LTS) מותקן במחשב.
- [ffmpeg](https://ffmpeg.org) להכנת הסרטון:
  - **Windows:** פותחים PowerShell ומריצים `winget install Gyan.FFmpeg`
  - **Mac:** `brew install ffmpeg`

### 2. הפעלת R2 (האחסון של הסרטונים)
ב-Cloudflare Dashboard ‏← **R2 Object Storage** ‏← מפעילים.
Cloudflare עשויים לבקש כרטיס אשראי כדי להפעיל R2, אבל **עד 10GB אחסון לא משלמים כלום**, ואין תשלום על תעבורה/צפיות.

### 3. הורדת הפרויקט והתקנה
פותחים טרמינל (ב-Windows: PowerShell) בתיקיית הפרויקט:

```bash
npm install
npx wrangler login                          # נפתח דפדפן, מאשרים גישה לחשבון
npx wrangler r2 bucket create video-vault   # יוצר את מקום האחסון
npx wrangler kv namespace create CODES      # יוצר את מאגר הקודים
```

הפקודה האחרונה מדפיסה `id = "..."`. מעתיקים את ה-id לקובץ `wrangler.toml` במקום `REPLACE_WITH_YOUR_KV_ID`.

### 4. סיסמאות
```bash
npx wrangler secret put ADMIN_PASSWORD   # הסיסמה שלך לפאנל הניהול. לבחור סיסמה ארוכה וחזקה!
npx wrangler secret put SESSION_SECRET   # מחרוזת אקראית ארוכה (אפשר להקליד 40 תווים אקראיים)
```

### 5. העלאה לאוויר
```bash
npx wrangler deploy
```
בסוף יודפס הכתובת של האתר, משהו כמו `https://video-vault.<השם-שלך>.workers.dev`.
(אם יש לך דומיין משלך, אפשר לחבר אותו ב-Dashboard ‏← Workers ‏← video-vault ‏← Settings ‏← Domains.)

## שימוש שוטף

### א. הכנת הסרטון (במחשב שלך)
הסקריפט ממיר את הסרטון לקטעים מוצפנים (עד 1080p).

- **Windows:** גוררים את קובץ הווידאו אל `scripts\prepare-video.bat`.
  או מהטרמינל: `scripts\prepare-video.bat "C:\Videos\my movie.mp4" my-movie`
- **Mac/Linux:** `./scripts/prepare-video.sh "/path/to/movie.mp4" my-movie`

נוצרת תיקייה `out/my-movie` (ב-Windows: בתוך `scripts\out\`). סרטון של שעה בערך 2–3GB אחרי ההמרה.

### ב. העלאה
נכנסים ל-`https://<האתר-שלך>/admin` ‏← לשונית **סרטונים והעלאה** ‏← בוחרים את התיקייה ‏← **העלאה**.
אם ההעלאה נקטעה, לוחצים שוב והיא פשוט תעלה הכל מחדש.

### ג. יצירת קודים
לשונית **קודי צפייה**:
1. כותבים שם צופה (או כמה שמות, שורה לכל אחד, וכל אחד יקבל קוד משלו).
2. בוחרים סרטון, תאריך ושעת תפוגה ומספר מכשירים.
3. **צור קוד** ‏← בטבלה לוחצים **העתק הודעה** ושולחים לצופה בוואטסאפ/מייל.

בטבלה אפשר בכל רגע:
- **שנה תוקף**: להאריך או לקצר.
- **אפס מכשירים**: אם הצופה החליף מחשב/דפדפן או ניקה cookies.
- **בטל / שחזר**: חוסם מיד, גם אם הוא באמצע צפייה (תוך עד 5 דקות).
- **מחק**.

### מה הצופה רואה
נכנס לכתובת האתר ‏← מקליד קוד ‏← הסרטון נפתח, עם השם שלו כסימן מים.
החיבור נשמר 12 שעות (אפשר לשנות `SESSION_HOURS` ב-`wrangler.toml`), אחר כך מזינים את הקוד שוב.

> שים לב: מצב גלישה בסתר או ניקוי cookies נחשבים "מכשיר חדש". אם צופה נתקע, לוחצים **אפס מכשירים**.

## מגבלות המכסה החינמית של Cloudflare
- **אחסון R2:** ‏10GB. מספיק לכמה שעות וידאו.
- **בקשות Worker:** ‏100,000 ביום. כל 6 שניות וידאו הן בקשה אחת, כלומר צפייה מלאה בסרטון של שעה ≈ 600 בקשות, **בערך 150 צפיות מלאות ביום**. אם צריך יותר, התוכנית בתשלום עולה $5 לחודש.
- **כתיבות לקודים (KV):** ‏1,000 ביום. כל כניסה עם קוד היא כתיבה אחת, אז זה מספיק בשפע.

## מבנה הקוד
- `src/worker.js`: השרת: התחברות, בדיקת קודים ותוקף, נעילת מכשיר, הגשת הווידאו המוצפן, API לניהול.
- `public/`: הדפים: `index.html` (הזנת קוד), `watch.html` + `watch.js` (נגן + סימן מים), `admin.html` + `admin.js`.
- `scripts/prepare-video.*`: המרה ל-HLS מוצפן עם ffmpeg.
